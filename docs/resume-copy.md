# GitHub 与在线简历可复制文字

## GitHub 仓库简介（短版）

基于 Apache Hive 的电商订单离线数仓练习项目。使用可复现模拟数据实现 ODS→DWD→DWS→ADS SQL 流水线，涵盖最新状态去重、动态分区写入、DAU/GMV/付费转化率、窗口指标与数据质量校验。仓库包含 Python/SQLite 本地逻辑验证和 Hive 4.0.0 Docker 运行配置。

## 在线简历项目经历（当前已完成状态）

**项目名称：** 电商订单离线数仓与每日经营指标（个人项目，模拟数据）

**技术：** HiveQL、SQL、Python、SQLite、Docker Compose 配置

- 设计 ODS、DWD、DWS、ADS 四层表结构，编写订单与行为数据的去重、清洗、汇总及趋势计算 SQL。
- 使用 `ROW_NUMBER()` 处理订单状态更新与重复上报；以动态分区和 `INSERT OVERWRITE` 设计可重跑的日汇总流程。
- 定义并计算 DAU、付费用户、支付订单数、GMV、付费转化率及三日滚动 GMV；编写唯一性、异常值和指标对账检查。
- 用 Python 生成固定种子的模拟数据，使用 SQLite 验证仓库中 SQL 的核心查询逻辑与预期结果一致。

**验证边界：** 目前未在真实 Hive 环境运行端到端流水线，因此不要写“上线”“生产部署”“Hive 实测性能提升”等表述。运行后可补充真实的环境、执行日志和校验结果。

## 面试时的一分钟讲法

“我做了一个电商订单离线数仓练习。原始层保留订单状态变更和用户行为；明细层先按订单编号取最新版本，再做质量过滤，避免旧状态回退；汇总层按业务日期计算 DAU、支付订单、GMV 和付费转化率；展示层用窗口函数算滚动 GMV 与日环比。SQL 使用动态分区和覆盖写入，便于同一业务日重算。我用固定种子的模拟数据和 SQLite 对核心查询做了校验；仓库也提供 Hive Docker 运行配置，Hive 端到端验证还需要在有运行环境时完成。”
